# Handshake NFC Cards

Single-page storefront for NFC business cards. Edit `src/store.html`, then run `./build.sh` to regenerate `index.html` for GitHub Pages.

- `fonts/`: self-hosted fonts and their SIL Open Font License files
- `emails/`: order confirmation and marketing email templates
- `docs/COMPLIANCE.md`: privacy, accessibility and consumer-law checklist, plus the owner to-do list before launch
